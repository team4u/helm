# 历史资料归档索引

本目录是 Helm 的历史资料库，只保存三类过去时点的记录：**设计推演**（阶段方案与取舍）、**开发交接**（能力交付时的交接说明）与**阶段验收**（修复或加固完成时的验收数据）。这些文档只记录当时的设计决策与验证事实，**不是当前的架构、接口或行为契约**：其中的命令、端口、包结构、插件清单与测试统计均可能已与现状不符，请勿据此理解或使用当前系统。

查阅现状请一律以 `docs/` 主目录的现行文档为准，本目录仅用于演进追溯与背景查证。归档文档只读，不再随代码演进修改，保留当时的提交节点、测试统计与设计语境；另有少量早期 Web 界面细节设计文档（暗黑主题、状态圆点、资源中心矩阵等）已随演进清理，可在 git 历史中追溯。
