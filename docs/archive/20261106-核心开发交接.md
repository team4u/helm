## 当前关键契约

1. 内核不硬编码业务角色。角色由 Profile 表达，tags 表达运行态或生命周期。Scope 字段之间 AND、数组内 OR、缺省不限、空数组不匹配。
2. 工具声明按会话过滤，执行时再查当前会话并检查 Scope。人工 HTTP/CLI 动作不带 conversationId 时不受会话策略限制，仍需鉴权；run_action 和工作流动作必须带所属会话。
3. createAsk 返回 `{ id, status, answers }`，status 为 answered/cancelled/superseded；取消和已由其他界面处理正常 resolve，answers 为 `{}`。验证、存储或宿主失败 reject；先登记 waiter，终态确认落盘后才交付，不覆盖重复预分配 ID。
4. `ctx.host.manageConversation(id)` 自动绑定声明插件。删除托管会话在 abort/清理前拒绝；停用和回滚释放管理权及监听。
5. 只有 `ctx.doc(name, initial, { public: true })` 经 HTTP/CLI 读取并推送更新；私有、未声明、停用或不存在均 404。ctx.route 使用插件相对路径，由宿主加命名空间。
6. ConversationDetail 为 summary 加 entries/nextCursor；assistant 文本在 entry.model。CLI/HTTP 输入 meta 落入 helm.input.data.meta，并传给 turn_settled.inputs。
7. SSE 为 snapshot + 增量事件，无历史事件重放；snapshot 含 ui/workflowRuns。live.text 是累计快照。plugin.changed 携带当前 UI，停用/卸载为 `[]`，包括 stop 失败后实际已完成的状态变更。
8. 模型为会话覆盖 > Profile.model > 全局；全局为启动参数 > HELM_MODEL > config.json.model。空模型表示未配置；PATCH 空串清覆盖。切换 Profile/下次输入重算，未配置时 submitInput 显式 model_not_configured。损坏 Profile 为 profile_read_failed，已绑定 Profile 缺失为 profile_not_found；不能悄悄调用全局模型。仅省略 profileId 才选择 assistant，显式 default 必须真实存在。
9. 受管进程 Token 仅内存有效，供 Shell CLI 访问真实 Hub；剥除继承 Token、统一脱敏、关闭失效。CLI 凭据只写独立 cli-token（0600）；环境 HELM_TOKEN 优先并短路磁盘读取。
10. spawn 元数据为 onResolved/onGateResult；外部 executionId 带 gate 却未回报结果必须 gate_result_missing，不猜目录或重复执行 gate。工作流结算等待插件清理，snapshot 通过 provider 获取运行摘要。
11. 工作流历史索引损坏为 workflow_index_corrupt（500），记录损坏或读取失败为 workflow_record_corrupt（500），附可识别 runId/key；不返回少项成功，不自动修剪记录。普通 getRun 不存在仍为 404。
12. CLI 支持 conversations list --profile/--status、send --meta --wait、workflows run --wait、workflows runs、plugins doc。两个 wait 对应 HTTP `?wait=1`；send 等待本次 SDK Submission 的回答，结果为 `{ conversationId, submissionId, text, entry }`，text 是回答；失败/中止显式报错且 CLI 非零退出。

## 实际边界与后续范围

- faux 仅用于本地验收；没有用真实外网模型完成端到端调用。
- worker_threads + node:vm 用于可终止执行与确定性，不承诺恶意脚本安全沙箱。

- SecretStash 不落库、不进模型上下文；可信 Shell 与进程内插件仍有宿主权限，可读取环境和内存。
