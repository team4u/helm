## 范围与入口

- `packages/kernel/src/builtin-plugins/herdr.ts`：插件工厂、服务、动作和生命周期；同目录 `herdr/` 拆分传输、执行、审批、归属和状态投射。
- `createHelm` 默认注册停用的 `builtin:herdr`。普通内核启动不要求 Herdr 在线；先通过 `plugins config` 配置，再启用。开关写入 `config.json.pluginEnabled`，重启沿用。
- `subagent` 完整传递 `agentType/cwd/isolation/resume/schema/gate/model/effort`；执行元数据通过 `onResolved` 独立回报 `executionId/effectiveCwd/worktree`。工作流经过同一 `agent_spawn` 管道。
- 本机使用官方 Unix socket RPC；远端使用 SSH stdin 中的 Python 3 标准库脚本。请求和环境进入 stdin / RPC 请求体，机密环境值不进入 SSH 或 Herdr 的进程参数；失败时不回退本机。
- 本轮未实现 Web 外壳、SuperAgent、triggers 或外部插件编译器。用户对设计文档的修改继续独立保留，未加入本轮提交。

## 执行、环境与归属

一次启用时解析并固定本机 socket 路径，优先级为显式 `socketPath`、继承的 `HERDR_SOCKET_PATH`、`session` 对应路径、默认路径。窗格持久记录真实 `target` 与 Profile / CLI kind 路由。命令、事件、文件、状态投射和清理使用一致目标；连接配置变更在下次启用生效。

新任务目录按请求、Profile 的 `runtime.workspace`、父会话目录、Hub 默认目录依次解析。Worktree 建立后按其实际目录重建环境。环境只注入 Profile 声明值、SecretStash 和受管变量；managed/stash 优先于 Profile。建窗时的实际环境仅保存在内存，Gate 和续接复用同一环境，不将机密写入插件文档。远端未显式配置可达 HTTP(S) `runtime.env.HELM_HUB_URL` 时，剥除本机 Hub 地址与 Token。

启动不能只看 `idle`：Herdr 会在尚不可输入时先返回 `idle`。执行器在启动预算内等待权威 `interactive_ready`，启动期间 blocked、首轮 blocked 和自愈 blocked 共用审批桥。每个长 RPC 接收取消信号，启动、执行、Gate、文件交接失败均进入统一收尾；普通失败登记 `failed`、释放 liveTasks 并保留脱敏诊断，中止等待自有资源清理完成。

任务必须写唯一 `.helm/wf-out-*.json|md` 文件，插件读取、校验、脱敏后删除。首次缺文件、JSON 或 Schema 不合格会在原窗格追问一次；其他 IO、权限、SSH、协议错误直接失败并附终端最后 40 行脱敏诊断。终端文本不能冒充交接结果。

Gate 在实际 cwd 与同一环境执行一次，经 `onGateResult` 回报。外部后端没有回报 Gate 时显式 `gate_result_missing`，工作流不能在本机猜测远端目录补跑。成功窗格保活供同一父会话和同一 workflow 轨道续接，结算后关闭；Worktree 磁盘和 Git 分支保留。并发 resume 只有一个请求可以占用原窗格，显式改变 kind、Profile、machine 或 cwd 会被拒绝。

清理前重新核对精确 Agent 名称和 tab 归属，只关闭自建 tab。Herdr 会在最后一个 tab 关闭时回收空 workspace；插件不主动关闭整个共享工作区或关联工作区组。身份变化时放弃关闭。失败现场保留；启动对账不会把 working、blocked 或 unknown 当作已完成。人类窗格不能自动发送按键或中止。

## 审批与通用机制

Ask 按 machine、pane 与权威 `state_change_seq` 单飞。发送按键前复核水位和精确 Agent 身份；已结算墓碑保留至水位偏离，防止重复创建与发键。审批等待期间查询权威状态，覆盖无 socket 事件的远端；首次销单早于 Ask 入库而返回 404 时继续复核，避免晚入库的 pending Ask 残留。read/focus 动作支持 machine 消歧，包括明确的 `machine: 'local'`。

通用 Ask resolver 支持异步 IO；等待后重读持久行，阻止并发回答、取消或 CAS 水位改写覆盖终态。非法水位错误保持 JSON-safe。插件启用在服务启动和配置持久化全部完成后才准入；服务 `liveTasks()` 保护运行和待续接资源。插件配置在文件锁内读取并更新最新值，避免覆盖鉴权或其他插件配置。

工作流的成功账本前缀逐项复用，包含已完成的 resume 和 action。相同脚本重放不重复模型、动作或 Gate；前缀失配后若只剩缓存结果而无活子上下文，续接显式失败。Gate 命令纳入调用键。`WorkflowNodeState.cached` 从引擎进度投射到公开摘要、事件和持久记录，HTTP 与 CLI 返回同一形状。

SecretStash 的承诺是 Helm 不将登记值落库或送入模型；可信 Shell、插件及外部 CLI 仍拥有各自环境和工具访问权限。外部 CLI 的工具输出、日志和模型上下文遵循其自身策略。
