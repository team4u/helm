## 后续补强与最终验收

- 生产工具接入会话作用域 EnvFabric，统一受管环境变量合成；会话删除和靶点变化释放缓存，无会话环境不进入持久缓存。远端输出 sink 按执行生命周期注册和释放。逐调用身份变量的大小写变体不能覆盖 composer 的权威值。
- 流式命令的 Hub 端聚合预算收紧至 256KiB；超过预算明确返回 `output_limit_exceeded`，逐块输出继续交付，不伪造完整聚合成功。非流式模式保留原有显式输出上限。
- 长期记忆上限移入文件锁内部，对合并结果检查，覆盖同 Profile 并发写入及管理 API/CLI 保存。缺失资产向模型和用户明确诊断，恢复后允许再次告警。
- 派工回滚覆盖创建后的整段副作用；只读 recall 工具不再写 doc。Watchdog 外部目标的去重淘汰增加 24 小时门槛，避免瞬时探针缺失导致近期动作重放。
- 输入追踪按 requestId 合并唯一记录，限制重建区间；重启恢复按 SDK submission 与 entry 的权威关系读取来源、元数据和附件。多回合后中止不再消费旧历史。停观删除观察令牌，迟到异步结算不得复活状态。
- `client.tsx` 实际可用：可信插件定义提供 `clientRoot`；esbuild 编译真实依赖闭包，逐文件验证根目录约束；共享 React 与 `@helm/plugin-client` 上下文；HTTP 鉴权分发与 `helm plugins client` 同权。全部内容槽支持通用组件渲染，编译和导出错误明确显示。
- 真实浏览器验证：别名导入加载、本地 React 计数、服务端 action 写公开 doc 并由 SSE 更新组件、打开助理分屏、停用后撤下组件。浏览器未报告运行时错误。测试插件和运行数据均在临时目录。
- 同步主树并行推进的模型供应商生命周期与 Magpie 改动，修正其测试夹具类型及启用契约断言，保留新功能。

完整构建、类型检查与最终全量测试结果记录在本节下方。

## 审计结论更正

JavaScript 的 `Math.abs(-2147483648)` 返回 `2147483648`。此前将其描述为负数是错误的。移除 32 位输入键哈希的有效理由是哈希碰撞，而非该数值边界。

## 验收边界

- 测试使用临时 helm 数据目录，未修改旧系统运行数据。
- 浏览器烟测使用隔离的 Hub 与 Web 服务，未替换用户正在运行的开发服务。
- 单测使用 faux provider 的场景是明确的测试夹具，不代表真实模型服务验收。
- 尚未对真实 Windows/macOS 节点执行现场验收；相关路径和管道行为由自动化测试覆盖。
- 插件客户端当前支持根目录内本地依赖与明确列出的宿主共享模块，不提供 npm 安装或任意包加载。
- 共享完整 lucide 命名空间增大了前端主包（约 1.77MB，gzip 约 394KB）；构建仍有 chunk 大小提示，未将其伪报为构建失败。
- 本次针对已发现问题加固并验收，不等价于对未来所有插件及运行环境的无缺陷保证。
